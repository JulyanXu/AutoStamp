# AutoStamp — 批量盖章桌面应用设计文档

## 概述

AutoStamp 是一个桌面应用程序，用于将透明底印章图片批量加盖到 Word、Excel、PDF 文件上，最终输出为盖好章的 PDF 文件。用户可以自由拖拽定位印章位置、调整大小和透明度、选择盖章页码范围。

**目标用户**：非技术人员，Windows 系统，双击 .exe 即可运行，无需安装依赖。

## 技术栈

- **语言**：Python 3.11+
- **界面框架**：PySide6 (Qt6)
- **PDF 操作**：PyMuPDF (fitz)
- **图片处理**：Pillow
- **文件转换**：LibreOffice Portable（内嵌，命令行 headless 模式）
- **打包工具**：PyInstaller（目录模式）

### 交互细节

- **文件列表**：支持拖拽文件进来，也可点击"添加文件"按钮选择；支持多选删除；同一文件自动去重
- **预览区**：选中文件时自动转换并预览第一页；印章图片以半透明覆盖层显示，可用鼠标拖拽定位；支持翻页浏览
- **印章设置面板**：大小滑块（10%-200%）、透明度滑块（10%-100%）、页码规则单选 + 自定义输入
- **底部**：开始按钮 + 进度条，处理过程中显示当前进度

## 核心逻辑

### 文件转换 (converter.py)

- 调用内嵌的 LibreOffice Portable：`soffice --headless --convert-to pdf`
- .docx / .xlsx → PDF，已经是 PDF 的文件直接跳过
- 转换结果存放在临时目录，处理完成后清理
- 自动检测操作系统，选择对应的 LibreOffice 路径：
  - Windows：程序目录下的 `libreoffice/` 子目录
  - macOS：系统安装的 LibreOffice（用于开发调试）

### 盖章处理 (stamper.py)

- 使用 PyMuPDF (fitz) 打开 PDF
- 根据位置坐标、大小比例、透明度，将印章图片插入指定页面
- 位置坐标以页面左上角为原点，单位为 PDF 点（1点 = 1/72 英寸）
- 预览区的像素坐标按比例换算为 PDF 坐标
- 支持 PNG 透明底图片

### 批量引擎 (batch.py)

- 遍历文件列表，逐个执行：转换 → 盖章 → 保存
- 在 QThread 子线程中运行，不阻塞界面
- 通过 Qt Signal 向主线程报告进度
- 单个文件失败时记录错误并继续处理下一个
- 批量完成后弹窗汇总：成功数量、失败文件列表

### 配置持久化 (config.json)

保存并自动加载上次使用的设置：

```json
{
  "stamp_path": "path/to/stamp.png",
  "stamp_scale": 100,
  "stamp_opacity": 100,
  "stamp_x": 50.0,
  "stamp_y": 50.0,
  "page_mode": "first",
  "custom_pages": "",
  "output_dir": ""
}
```

### 输出规则

- 输出文件名：`原文件名_已盖章.pdf`
- 默认输出到源文件同级目录下的 `output/` 文件夹
- 可通过设置面板自定义输出目录

## 错误处理

| 场景 | 处理方式 |
|------|---------|
| 不支持的文件格式 | 添加时过滤，只接受 .docx / .xlsx / .pdf，其他弹提示 |
| 印章图片无效 | 加载时校验，非图片或损坏文件给出提示 |
| LibreOffice 未找到 | 启动时检测，未找到时弹窗提示 |
| 单个文件转换失败 | 跳过并记录，批量完成后统一展示失败文件 |
| 输出文件被占用 | 提示用户关闭后重试 |
| 空文件列表 | 点击"开始盖章"时提示"请先添加文件" |
| 未选择印章 | 提示"请先选择印章图片" |

## 打包与分发

- **PyInstaller 目录模式**：打包成文件夹，包含 .exe 和所有依赖
- **LibreOffice Portable**：放在打包目录的 `libreoffice/` 子目录中
- **交付方式**：整个文件夹压缩为 .zip，对方解压后双击 `AutoStamp.exe` 运行
- 不使用单文件模式（启动慢，LibreOffice 体积大不适合）

### Mac 开发调试

- Mac 上使用系统安装的 LibreOffice（`brew install --cask libreoffice`）
- 程序自动检测操作系统，选择对应路径

## 支持的文件格式

| 输入格式 | 说明 |
|---------|------|
| .docx | Microsoft Word 文档 |
| .xlsx | Microsoft Excel 表格 |
| .pdf | PDF 文档（直接盖章，无需转换）|

输出格式统一为 PDF。
